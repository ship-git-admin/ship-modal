# Ship Modal

## 1.8.5での更新・同意制御の変更

- 自動更新はGitHub Releaseと一致するクリーンなRelease Assetがある場合だけ検出します。タグZIPやmainブランチへフォールバックしません。
- 同意撤回後に再同意した場合も、対象GA4測定IDの初期化を再送します。
- CMPの初期値が`false`、`0`、空文字列の場合も未同意として扱います。

## 1.8.4でのセキュリティ・同意制御の変更

- 公開イベントは`event_id`が必須です。空・不正な値はHTTP 400で拒否します。
- 旧固定トークンは終了し、発行時刻付き署名トークンのみを受け付けます。デプロイ時はページ／CDNキャッシュを更新してください。
- 重複排除はイベント単位のDB transientではなく、専用テーブルの一意キーで行います。

WordPress向けのモーダル管理プラグインです。

## 主な機能

- 固定フレーム（画像のみ / 画像＋テキスト / テキスト / ページャー）
- 基本画像のalt設定、スマホ用画像（任意）のレスポンシブ切り替え（767px以下）
- 入力を止めないサニタイズ保存と画面幅に応じた自動折り返し
- 画像＋ボタンの複合レイアウト（画像位置：上・左・右）
- 複数ページのページャー（ページごとに画像・見出し・本文・ボタン）
- 中央カード、下部バナー、右下ポップアップ、フルスクリーンの4デザイン
- トップページ / 投稿・固定ページ / 指定ページ / ショートコード / 全ページの表示範囲（新規作成時はトップページのみ）
- 公開中の固定ページ・投稿・カスタム投稿タイプから表示先を複数選択
- 表示対象を1つのUIに統合し、タイトル検索・投稿タイプ絞り込み・選択チップで管理
- モーダルごとのborder-radius、padding、max-width設定（px）
- 画像専用モードでは角丸・内側余白の入力欄を一時非表示（将来フラグで再表示可能）
- 基本画像選択時にPC画像の横幅を最大幅へ自動入力（必要に応じて手動変更可能）
- ボタン文言は1行10文字・最大2行（`<br>`で改行）に制限し、保存時の超過分を自動調整
- 自動表示 / スクロール到達 / 離脱意図 / ボタン表示、遅延秒数、開始・終了日時
- 毎回、このタブで1回、端末の現地日付で1日1回、このブラウザで1回の表示頻度
- 表示回数・クリック数・クリック率の計測
- 閉じる回数・ページャー閲覧数の計測
- 日別集計、期間指定CSV出力、全計測データのリセット
- GTM/GA4連携（既存gtagの自動検出、測定ID指定による直接送信、dataLayerフォールバック）
- ESC、閉じるボタン、背景クリック、フォーカストラップ
- ページャーの前後移動、ドット移動、左右矢印キー
- GitHub Release Assetを配布元に限定した自動アップデート（Plugin Update Checker）

## 現行の入力モード

現行リリースでは運用方針により、管理画面の内容入力を画像専用に一時制限しています。既存のHTML・テキスト・ページャーの保存データは削除せず、公開表示も維持します。HTML等の入力を再開する場合は、プラグイン読込前に `SHIP_MODAL_IMAGE_ONLY_MODE` を `false` として定義するか、`ship_modal_image_only_mode` フィルターで `false` を返してください。

ショートコード: [ship_modal id="123"]

## GA4連携

「モーダル」→「計測・GA4連携設定」でサイトのGA4測定ID（`G-XXXXXXXXXX`）を一度設定すると、GTMにモーダル用のカスタムイベントタグを追加しなくても、表示・クリック・閉じる・ページャー閲覧イベントをGA4へ直接送信できます。ページ上に既存の `gtag()` がある場合は、測定IDを空欄にしても自動検出して利用します。

送信方式は「自動（推奨）」「GA4へ直接送信」「GTMのdataLayerのみ」から選択できます。GTM側で同じイベントをGA4へ転送している場合は、二重計測を避けるため「GTMのdataLayerのみ」を選択してください。プレビュー中は計測しません。

Cookie同意管理（CMP）と連動する場合は、初期状態を `ship_modal_ga4_enabled` フィルターで返し、ページ表示後の変更時は `window.ShipModalConsent.setAnalyticsConsent(true)` / `false` を呼び出してください。`false` の間はGoogleタグとGTM向けdataLayerの双方へイベントを送信しません。`true` に戻した後に発生するイベントから再開します。フィルター未設定時は従来互換で送信を許可します。

```js
// CMPの同意状態が変わったタイミングで呼び出す（文字列ではなく真偽値を推奨）。
window.ShipModalConsent.setAnalyticsConsent(consentGranted === true);
```

公開計測APIはページ上で誰でも呼び出せるため、GA4同意の制御は必ず利用中のCMP／GTM設定側でも確認してください。

公開計測には、発行時刻付きの署名トークン、必須のイベントID、専用テーブルの一意キーによる短期重複排除、匿名化した一時レート制限を使います。同じ送信のリトライは1回だけ集計されます。統計は広告・不正アクセスの影響を完全には受けない監査値ではないため、重要な判断ではGA4等の外部計測も併用してください。

## 対応環境

- WordPress 4.8以上（WordPress 4.8.12 / PHP 7.4.33で動作確認済み）
- PHP 7.4以上が必要
- GitHubの自動アップデートにはPHPのJSON拡張が必要です。
- 開始前のモーダルは非表示のまま待機し、ページを開いたまま開始・終了時刻を迎えた場合もフロント側で表示状態を切り替えます。
- 期間指定は画面上の表示制御です。開始前の内容もHTMLソースには含まれるため、公開前の機密情報には使用しないでください。
